## 📁 Standard Application Directory Layout

For each company and role, a dedicated folder is created under `resume-applications/`:

```text
resume-applications/
└── <Company>_<Role>/
    ├── Rithish_S_Resume.tex     # Tailored single-page LaTeX resume optimized for ATS
    ├── JD_Analysis.md           # Requirements extraction, Keyword Tiers 1-5, Gap Analysis table
    └── SUMMARY.md               # Top requirements, matches, gaps, project selection & rationale
```

## 🎯 Application Status Key
- 📝 **Drafted / Analyzed**: Resume analyzed and tailored, awaiting submission.
- 📤 **Applied**: Application submitted via portal / referral.
- 📞 **Screening**: HR / Recruiter phone screen scheduled/completed.
- 💻 **OA / Tech Round**: Online assessment or technical interview.
- 🤝 **Final Round**: Onsite / System Design / Culture round.
- 🎉 **Offer**: Offer received.
- 📁 **Archived**: Closed or rejected.
