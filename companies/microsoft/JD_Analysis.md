## 1. Role Overview & Core Expectations

Microsoft's Software Engineering Internship program places interns into core product engineering teams where they contribute directly to high-impact, planet-scale services and client software. Interns are expected to:
- **Design, Develop & Test:** Apply sound engineering principles to solve complex algorithmic, architectural, and systems problems.
- **Master Core CS:** Demonstrate deep proficiency in Data Structures, Algorithms, Object-Oriented Programming (OOP), Operating Systems, Concurrency, and Database Management.
- **Ensure Software Rigor:** Write clean, modular, maintainable, and thoroughly tested code with test automation, handling boundary conditions and precision requirements.
- **Collaborate & Communicate:** Work cross-functionally with engineers, Product Managers, and technical leaders, iterating rapidly based on code reviews and feedback.
